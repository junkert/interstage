# Directory index

Propose-only. Put each draft in the specialist report; the orchestrator stores it at `evidence/index-proposals/<mirrored path>/_index.md` in the mission directory.

Write into the repository only at paths a TODO item names, as one commit (`<TODO-ID>: <imperative title>`). Treat every existing `_index.md` as human-written unless it carries a generated marker (for example a first-line comment `<!-- generated by interstage -->`). Never overwrite a human-written one; propose a diff in the report instead. Add that marker to files you write.

## Template

```markdown
<!-- generated by interstage -->
# Directory: <path>/

## Purpose
<one or two sentences from what the code does>

## Contents
- **<name>/** - <one-line role>

## Conventions
- <convention observed in the code, with a file:line example>

## Related Directories
- `<path>/` - <relationship>
```

## Rules

- Describe only what the files show; mark unknowns as `Unknown`.
- List names and roles only, not the contents of subdirectories.
- Keep it short; no dates, counts, or coverage figures.
- Do not assume team structure or process.
- Skip generated, vendored and build-output directories.

## Monorepo

Index the repo root and each package or app root; link packages from the root index.
Shared code gets its own index naming which packages consume it.
