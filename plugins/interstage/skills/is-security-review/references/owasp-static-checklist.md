# OWASP static checklist (Top 10, 2021 edition)

Static inspection only. Every finding needs file:line evidence; never print secret values. "Reachable" means a route, job or entry point in the repository leads to the code. Unknown reachability or mitigation downgrades one level and is marked `[INFERENCE]`.

| Category | Static check | Evidence required | Severity rule |
|---|---|---|---|
| A01 Broken Access Control: missing authorization (CWE-862) | Handlers for state-changing or data-returning routes: is there an authorization check before the action? | Handler file:line plus the absent or bypassed check, and the route registration | blocker if state-changing and reachable; major if read-only sensitive data; minor otherwise |
| A01: insecure direct object reference (CWE-639) | Handlers that load a record by a request-supplied id without comparing owner or tenant | Lookup file:line and the missing ownership comparison | blocker if reachable and tenant or user data; otherwise major |
| A01: path traversal (CWE-22) | File reads, writes or extraction using request-supplied paths without normalization and a base-directory check | Sink file:line and data flow | blocker if reachable write; major if reachable read |
| A01: cross-site request forgery (CWE-352) | State-changing routes authenticated by cookie with no anti-CSRF token or same-site control | Route file:line and session config | major |
| A02 Cryptographic Failures: weak algorithm (CWE-327) | MD5, SHA-1, DES or ECB mode used for a security purpose | Call site file:line and its purpose | major for security use; minor for non-security checksums |
| A02: weak password hashing (CWE-916) | Passwords hashed with a fast or unsalted hash, or with low work-factor parameters | Hashing call file:line and its parameters | major |
| A02: weak randomness (CWE-338) | Tokens, session ids or reset codes generated by a non-cryptographic PRNG | Generator call file:line and what the value protects | major if it protects authentication or sessions; minor otherwise |
| A03 Injection: SQL (CWE-89) | Queries built by concatenation or interpolation with request data instead of parameters | Sink file:line and data flow from input | blocker if reachable |
| A03: OS command (CWE-78) | Shell or process invocation with request data in the command string | Sink file:line and data flow | blocker if reachable |
| A03: cross-site scripting (CWE-79) | Unescaped output in templates; raw HTML insertion APIs fed by user data | Sink file:line and data flow | major; blocker if stored and rendered to other users with no encoding |
| A04 Insecure Design | Missing rate limits on authentication or expensive operations; trust placed in client-side checks; no abuse-case handling in specs | Spec clause or code file:line showing the missing control | major if a sensitive flow lacks the control; otherwise minor |
| A05 Security Misconfiguration | Debug mode in shipped config; permissive CORS; missing security headers; default credentials; root container; wildcard IAM; unencrypted storage; verbose errors | Config file:line | major for shipped wildcard IAM or root container; minor for missing headers |
| A06 Vulnerable and Outdated Components | Manifests and lockfiles: versions against advisories already present in provided audit output or lockfile metadata; floating versions | Manifest or lockfile file:line and the advisory id from the provided source | major if reachable and an advisory is cited; minor if unpinned only |
| A07 Identification and Authentication Failures: missing authentication (CWE-306) | Sensitive endpoints reachable without a login or token check; skipped signature or token verification | Route file:line and absent check | blocker if reachable and sensitive |
| A07: hard-coded credentials (CWE-798) | Keys, tokens or passwords in source, config, fixtures or committed `.env` files | File:line and key name only (redact the value) and what it appears to grant | blocker if live-looking; minor if clearly a placeholder or test fixture |
| A08 Software and Data Integrity Failures: unsafe deserialization (CWE-502) | Deserializing untrusted data with loaders that construct arbitrary objects | Call site file:line and input source | blocker if reachable with untrusted input |
| A08: CI integrity | CI actions or images unpinned; workflows that run untrusted input with secrets | Workflow file:line | major if secrets are exposed; minor if only unpinned |
| A09 Security Logging and Monitoring Failures: sensitive data in logs (CWE-532) | Log statements that include credentials, tokens or PII; no logging of authentication failures or access denials | Log call file:line | major for credentials or tokens; minor for PII or missing audit logs |
| A10 Server-Side Request Forgery (CWE-918) | Outbound requests whose URL derives from request data; allowlist or destination check present or absent | Request call file:line, data flow from input, and the absent allowlist | blocker if reachable, the URL is attacker-controlled and there is no allowlist; if reachability or control is not visible in the repository, downgrade one level and mark `[INFERENCE]` |
