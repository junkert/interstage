# interstage

A framework of agents and skills for [OMP](https://github.com/can1357/oh-my-pi) (oh-my-pi) used to build and maintain software projects. Hardware projects are planned for a later release.

Interstage installs as user-scope OMP plugins, so nothing needs to be checked into the projects you work on. You start it per session; plain `omp` stays stock.

Status: planning. Nothing is built yet. See [docs/DESIGN.md](docs/DESIGN.md) for the architecture, agent roster, mission lifecycle, install plan and spike results.
